# Lista de Tarefas - Trabalho Prático 03 (Scrum)

Aplicação web simples baseada nas histórias US01 a US05 selecionadas no documento.

## Funcionalidades

- US01 - Adicionar uma tarefa com título
- US02 - Visualizar todas as tarefas
- US03 - Marcar tarefa como concluída
- US04 - Excluir uma tarefa
- US05 - Editar título de uma tarefa

## Persistência

As tarefas são salvas no `localStorage` do navegador. Portanto, fechar e abrir a página mantém os dados no mesmo navegador.

## Como executar

Basta abrir o arquivo `index.html` em um navegador moderno.

Não é necessário servidor, banco de dados ou instalação de dependências.
